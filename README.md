# ECS Ready

A mobile-first revision app based on the supplied **ECS Health, Safety and Environmental Assessment Revision Guide (from 6 May 2024)**.

## What is included

- All 327 extractable multiple-choice questions and explanations from the supplied guide, across all 11 assessed areas
- Fresh-question sessions that do not repeat a question until the whole question cycle is complete
- Review-misses mode: incorrect answers stay queued until answered correctly
- Topic-only practice and 25-question mixed practice tests
- Scenario flashcards that give context before asking for a response
- Device-local learning progress, topic coverage and accuracy
- Responsive layout for iPhone and desktop
- A web app manifest and offline cache, so it can be installed after it is hosted

## Use it on PC and iPhone

1. Upload the contents of this folder to any static web host, such as GitHub Pages, Netlify Drop, Cloudflare Pages, or your school/company web space.
2. Open the resulting HTTPS address on your PC or iPhone.
3. On iPhone: Safari → Share → **Add to Home Screen**. On desktop: use the browser’s install-app option when available.

It does not send any answers or personal data anywhere; progress is stored only in that browser.

## Important

This is a learning companion, not an official ECS assessment or a replacement for the original guide. Check the current ECS materials before sitting an assessment.
